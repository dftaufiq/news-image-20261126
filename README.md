One image that sums up Thursday 26 November 2026: a newspaper front page with 36 verified stories across 9 regions — missiles over Riyadh and burning tankers in Hormuz as the dominant hero, Macy's 100th parade postponed, the EU summit on Kyiv's €45bn lifeline, a pin map, a UTC timeline and an honest DATE CHECK of what was left out. Every story was checked against live reporting on the morning of 26 November 2026; nothing was invented. All pictures are original drawings made for this entry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only) copies the committed `entry.png` to `/output/entry.png`. `generate_image.py` is the build-time generator that drew the front page (PIL); re-running it reproduces `entry.png` byte for byte from the same sources.
